## About this course

This course is for all who know how to write software in some programming language like Java, C#, or others, and who want to quickly navigate BBj to write for the GUI or for the browser. It explains the very first steps for setting up the development environment and then builds all the basic knowledge that a developer should know to successfully develop in BBj.

Start with [Set up your environment and get started](./01-getting-started/index.mdx).
