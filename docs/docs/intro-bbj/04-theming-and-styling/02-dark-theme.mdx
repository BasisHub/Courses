---
title: Switching your BBj app to dark theme
description: Switch your BBj app to the dark theme and add a toggle that changes the theme at run time.
---

BBj comes with a built-in theme that offers a dark mode. Switching to it takes one call to [`BBjWebManager::setTheme`](https://documentation.basis.cloud/BASISHelp/WebHelp/bui/BBjBuiManager/BBjWebManager_setTheme.htm):

```bbj
BBjAPI().getWebManager().setTheme("dark")
```

To follow the light or dark setting of the user's operating system instead, call `setTheme("system")`. The DWC documentation explains how [automatic dark mode](https://dwc.style/docs/#/theme-engine/themes?id=automatically-enable-dark-mode) works.

With that knowledge, you can improve your HelloButton program by adding a checkbox that switches dark mode on and off.

```bbj
declare BBjTopLevelWindow wnd!
declare BBjCheckBox cb!
declare BBjButton btn!

BBjAPI().getWebManager().setTheme("light")
wnd! = BBjAPI().openSysGui("X0").addWindow(10,10,800,600,"Hello BBj DWC",$01101083$)
wnd!.setCallback(BBjAPI.ON_CLOSE,"byebye")
wnd!.setStyle("margin","20px")
wnd!.setPanelStyle("display","inline-grid")
wnd!.setPanelStyle("gap","20px")

cb! = wnd!.addCheckBox(wnd!.getAvailableControlID(),0,0,0,0,"Dark Theme")
cb!.setCallback(BBjAPI.ON_CHECK_OFF,"toggleLightTheme")
cb!.setCallback(BBjAPI.ON_CHECK_ON,"toggleDarkTheme")
btn! = wnd!.addButton(wnd!.getAvailableControlID(),0,0,0,0,"Say Hello")
btn!.setCallback(BBjAPI.ON_BUTTON_PUSH,"sayhello")
process_events
sayhello:
    a=msgbox("Hello World")
return
toggleLightTheme:
    BBjAPI().getWebManager().setTheme("light")
return

toggleDarkTheme:
    BBjAPI().getWebManager().setTheme("dark")
return

byebye:
    release
```

Copy the code into your IDE and run it in DWC. Examine what happens when you switch to Dark-Mode.
