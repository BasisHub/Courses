---
title: "Bonus exercise: Add a computer player"
description: Turn your Tic-Tac-Toe game into a one-player game where the computer plays the other side.
---

:::exercise

This is an optional task to get yet more familiar with the BBj language and your new coding tools:

Make a copy of your Tic-Tac-Toe and try to move it into a one-player version where the computer plays the other player. Play a bit with the computer algorithm, what can you implement? Random moves, MinMax, what else?

:::
