In our better version of "Hello World" we have learned how to implement a callback for a Button-Push. This is already "user input". Taking user input from fields is pretty similar.

## Types of Input Fields

BBj knows a few different types of Input Fields, where users can directly enter data:

- [BBjEditBox](https://documentation.basis.cloud/BASISHelp/WebHelp/bbjobjects/Window/bbjeditbox/bbjeditbox.htm) - a simple, single line edit (which also has options to act as a password input)
- [BBjCEdit](https://documentation.basis.cloud/BASISHelp/WebHelp/bbjobjects/Window/bbjcedit/bbjcedit.htm) - a simple Multi-Line edit
- [BBjInputN](https://documentation.basis.cloud/BASISHelp/WebHelp/bbjobjects/Window/bbjinputn/BBjInputN.htm) - a control especially to enter numbers
- [BBjInputD](https://documentation.basis.cloud/BASISHelp/WebHelp/bbjobjects/Window/bbjinputd/bbjinputd.htm) - an input for dates
- [BBjInputE](https://documentation.basis.cloud/BASISHelp/WebHelp/bbjobjects/Window/bbjinpute/BBjInputE.htm) - an input control for Strings

plus:

- [BBjHTMLEdit](https://documentation.basis.cloud/BASISHelp/WebHelp/bbjobjects/Window/bbjhtmledit/BBjHtmlEdit.htm) - a built-in HTML Editor

Take some time to visit the documentation pages for each of these controls. Have a look at the method signatures, the events they offer, and the sample code that is listed in some of the chapters.

You can copy and paste the sample code into your IDE, run it there and examine it further. Do so for some of the examples from the docs to become more familiar with the documentation, BBj source code and the IDE.

## Masks

BBjInputE and BBjInputN use Masks to format user input. Read the documentation page about masks. Read about [String Output Masking](https://documentation.basis.cloud/BASISHelp/WebHelp/usr/BBj_Enhancements/string_output_masking_bbj.htm) and [Numeric Masks](https://documentation.basis.cloud/BASISHelp/WebHelp/usr/BBj_Enhancements/numeric_output_bbj.htm) in the Documentation.

**Note: Please recognize that some topics (like these two) are BBj-specific and come with links to the original, legacy topics that also apply for BBj.**

BBjInputD takes a Date Mask which is documented with the [DATE function](https://documentation.basis.cloud/BASISHelp/WebHelp/commands/bbj-commands/date_function_bbj.htm) ; also read about the [input taking](https://documentation.basis.cloud/BASISHelp/WebHelp/usr/BBj_Enhancements/date_input.htm) itself for this control.
