If you find an error, an unclear step or missing material, open an issue at [https://github.com/BasisHub/Courses/issues](https://github.com/BasisHub/Courses/issues).

Name the page and describe the problem or the suggestion. Short and concrete reports are the easiest to act on.

Every contribution is appreciated. Maybe some day you will find the improved material useful yourself, when you mentor a new colleague in development with BBj.
