---
title: "Exercise: Replace a grid with the BBjGridExWidget"
description: "Install the BBjGridExWidget, run its demos in GUI, BUI and DWC, and write a DWC program that shows CDStore data in a full-screen grid."
---

:::exercise

- Install BBjGridExWidget on your computer.
- Load the folder as a project into Eclipse.
- Run `Demo.bbj` from the demos.
- Run some other demos in GUI, BUI and DWC.
- Write a DWC program that shows the grid full-screen in the browser. Load all records from the CDStore `CDINVENTORY` table into this grid.

:::
