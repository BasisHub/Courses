## About this course

This course has 12 chapters that take you through the Dynamic Web Client, from first concepts to production deployment.

The chapters build on each other. You start with BBj GUI fundamentals and move on to advanced responsive design and deployment. Every lesson comes with runnable BBj source files, so you can experiment, change the code, and learn by doing. The [Sample Code](./samples.mdx) page explains how to get them. The [Exercises](./exercises.mdx) page lists every exercise of the course.

Along the way you learn the web standards that today's applications rely on: CSS Grid, Flexbox, web components, theming, and responsive design patterns.

Start with [GUI to BUI to DWC](./01-gui-to-bui-to-dwc/index.md).
