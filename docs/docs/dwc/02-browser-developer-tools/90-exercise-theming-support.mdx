Based on your previous work:

1. Create a custom theme file by visiting [https://us.bbx.kitchen/webapp/DWCThemer](https://us.bbx.kitchen/webapp/DWCThemer). Download it and apply it to your sample.

2. Add a switch to toggle between light mode and dark mode.

3. Add a separate CSS file and move the CSS styles from your BBj source file into it.
