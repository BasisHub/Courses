---
title: "Exercise: Lay out a form with CSS Flexbox"
description: "Switch a short form from flow layout to a CSS Flexbox column layout with setPanelStyle() calls on the window."
---

A possible solution is at the end of this page.

:::exercise

Open `Exercise-ConvertToCssFlexbox.bbj` from [05_CssLayouts.zip](pathname:///files/dwc/05_CssLayouts.zip) for the exercise source code.

This exercise displays a short form in a window with flow layout.

**Goals:**

1. Add a `window!.setPanelStyle()` call that sets the CSS `display` property of the window to `flex` to switch to a flexbox layout.

2. Add a `window!.setPanelStyle()` call that sets the CSS `flex-direction` property of the window to `column`, so the controls are laid out vertically.

3. Add `window!.setPanelStyle()` calls for padding around the window and a gap between the controls.

4. Note that the program uses the succinct versions of the `BBjWindow::addEditBox()` methods that take only the contents of the control, and chains the `BBjControl::setAttribute()` method to give each edit box a label in one line of code:

   ```bbj
   window!.addEditBox("Joe Blow").setAttribute("label", "Name:")
   ```

   `setAttribute()` returns nothing, so the program doesn't store the result of the chain in a variable. If you need the edit box later, store it first and call `setAttribute()` on the variable.

:::

<summary>Possible solution</summary>

The starter file is `Exercise-ConvertToCssFlexbox.bbj`. The solution is in `Exercise-ConvertToCssFlexboxComplete.bbj`, and you find all files in [05_CssLayouts.zip](pathname:///files/dwc/05_CssLayouts.zip).

```bbj title="Exercise-ConvertToCssFlexboxComplete.bbj"
rem /**
rem  * Exercise-ConvertToCssFlexboxComplete.bbj
rem  *
rem  * This is the completed version of the Exercise-ConvertToCssFlexbox.bbj exercise program.
rem  */


rem If the app is running in BUI, switch it automatically to run in the DWC client instead
rem ================================================================================
if (info(3, 6) = "5") then
    bui! = BBjAPI().getBuiManager()
    url! = bui!.getUrl().replaceAll("apps", "webapp")
    action! = bui!.urlAction(url!)
    bui!.setEndAction(action!)
    release
endif


sysgui = unt
open (sysgui)"X0"
sysgui! = bbjapi().getSysGui()
window! = sysgui!.addWindow("CSS Flexbox and Label Attributes",$00190083$)
window!.setCallback(window!.ON_CLOSE, "onClose")
window!.setPanelStyle("width", "100%")
window!.setPanelStyle("height", "100%")
window!.setPanelStyle("box-sizing", "border-box")
window!.setPanelStyle("display", "flex")
window!.setPanelStyle("flex-direction", "column")
window!.setPanelStyle("gap", "var(--dwc-space)")
window!.setPanelStyle("padding", "1em")


rem Add the controls to the window
window!.addEditBox("Joe Blow").setAttribute("label", "Name:")
window!.addEditBox("BASIS International Ltd.").setAttribute("label", "Company:")
window!.addEditBox("joeBlow@basis.com").setAttribute("label", "Email:")


process_events

onClose:
release

declare auto BBjSysGui sysgui!
declare auto BBjTopLevelWindow window!
```
