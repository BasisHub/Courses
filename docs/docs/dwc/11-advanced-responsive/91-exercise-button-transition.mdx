---
title: "Exercise: Add a transition to a button"
description: "Create a BBj program with a button that grows on hover, then add a CSS transition to make the animation smoother."
---

:::exercise

Create a small BBj file that has a button. Use CSS to make the button bigger when you hover over it, then add a transition to make the animation smoother.

As a reminder, this is the syntax of the transition:

```css
transition: <property> <duration> <timing-function> <delay>;
```

:::
