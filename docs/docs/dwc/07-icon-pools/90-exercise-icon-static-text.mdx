---
title: "Exercise: Add an icon to a static text"
description: "Add icons from the DWC icon pools to a BBjStaticText control and try different expanse and theme values."
---

A possible solution is at the end of this page.

:::exercise

Open `Exercise-IconPools.bbj` from [06_IconPools.zip](pathname:///files/dwc/06_IconPools.zip) for the exercise source code.

This exercise consists of a BBjStaticText control that contains the text `I like the following sports:`. In this exercise, you add icons to the text control for one or more sports using the icon pool capability of the DWC.

**Goals:**

1. Add one or more icons to the static text control. For a refresher on the syntax, look at the `DownloadButton.bbj` program in the same ZIP file.

2. Try setting an expanse and theme for the icons.

:::

<details>
<summary>Possible solution</summary>

The starter file is `Exercise-IconPools.bbj`. The solution is in `Exercise-IconPoolsComplete.bbj`, and you find all files in [06_IconPools.zip](pathname:///files/dwc/06_IconPools.zip).

```bbj title="Exercise-IconPoolsComplete.bbj"
rem /**
rem  * Exercise-IconPoolsComplete.bbj
rem  *
rem  * This is the completed version of the Exercise-IconPools.bbj exercise program.
rem  *
rem  */


rem If the app is running in BUI, switch it automatically to run in the DWC client instead
rem ================================================================================
if (info(3, 6) = "5") then
    bui! = BBjAPI().getBuiManager()
    url! = bui!.getUrl().replaceAll("apps", "webapp")
    action! = bui!.urlAction(url!)
    bui!.setEndAction(action!)
    release
endif

rem Create the window and use a grid layout
window! = BBjAPI().openSysGui("X0").addWindow("DWC Icon Pools", $00100093$)
window!.setPanelStyle("display", "inline-grid")
window!.setPanelStyle("grid-template-columns", "1fr")
window!.setPanelStyle("gap", "var(--dwc-space)")
window!.setPanelStyle("padding", "var(--dwc-space-xl)")
window!.setCallback(BBjAPI.ON_CLOSE, "onExit")


rem Change the line below to add one or more sports icons
label! = window!.addStaticText("<html>I like the following sports: "+
:                              "<bbj-icon pool='tabler' name='ball-tennis' expanse='s' theme='primary'></bbj-icon>"+
:                              " and <bbj-icon pool='fa' name='futbol' expanse='xs' theme='primary'></bbj-icon>, how about you?")


btnSubmit! = window!.addButton("Exit")
btnSubmit!.setAttribute("theme", "primary")
btnSubmit!.setAttribute("expanse", "xl")
btnSubmit!.setStyle("margin-top", "1em")
btnSubmit!.setCallback(BBjButton.ON_FORM_VALIDATION, "OnExit")


window!.setVisible(1)
process_events


rem ================================================================================================
rem Subroutines
rem ================================================================================================

rem Handle the user exiting the app
onExit:
release
```
