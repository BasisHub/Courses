Use this page to find all exercises of the course. Each exercise sits at the end of its chapter. Some exercises come with a complete solution on the page, as noted below.

## GUI to BUI to DWC

- **[Exercise: Take an app from GUI to BUI to DWC](./01-gui-to-bui-to-dwc/90-exercise-gui-to-bui-to-dwc.mdx)** - Run a BBj program in GUI, BUI and DWC, then change its layout and button attributes. (solution included)

## Browser Developer Tools, CSS, and Themes

- **[Exercise: Add theming support](./02-browser-developer-tools/90-exercise-theming-support.mdx)** - Create a custom DWC theme with a light and dark mode switch and move your CSS into a separate file.

## Upgrading Apps to DWC

- **[Exercise: Replace a grid with the BBjGridExWidget](./04-upgrading-apps/90-exercise-bbjgridexwidget.mdx)** - Install the BBjGridExWidget and show CDStore data in a full-screen grid.

## DWC Controls With Extended Attributes

- **[Exercise: Search in a BBjTree](./05-dwc-controls/90-exercise-search-bbjtree.mdx)** - Make a BBjTree scrollable, add a search field and change the leaf icons. (solution included)

## Flow Layouts and CSS for Responsive Design

- **[Exercise: Convert a form to a CSS grid layout](./06-flow-layouts/90-exercise-css-grid-layout.mdx)** - Turn a flow layout contact form into a two-column CSS grid. (solution included)
- **[Exercise: Lay out a form with CSS Flexbox](./06-flow-layouts/91-exercise-css-flexbox.mdx)** - Switch a short form from flow layout to a Flexbox column layout. (solution included)

## Icon Pools

- **[Exercise: Add an icon to a static text](./07-icon-pools/90-exercise-icon-static-text.mdx)** - Add icons from the DWC icon pools to a BBjStaticText and try different expanse and theme values. (solution included)

## Control Validation

- **[Exercise: Validate an email address](./08-control-validation/90-exercise-email-validation.mdx)** - Make the Email field required and add a pattern validation with a regular expression. (solution included)

## Embedding Third-Party Components

- **[Exercise: Embed a third-party component](./10-embedding-components/90-exercise-embed-component.mdx)** - Pick a component from Ionic or Shoelace and embed it in a BBj program.

## Advanced Responsive Design

- **[Exercise: Use media queries](./11-advanced-responsive/90-exercise-media-queries.mdx)** - Change the look of one of your programs with a CSS media query on the screen width.
- **[Exercise: Add a transition to a button](./11-advanced-responsive/91-exercise-button-transition.mdx)** - Make a button grow on hover and smooth the animation with a CSS transition.
