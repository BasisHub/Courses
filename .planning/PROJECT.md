# BASIS Courses

## What This Is

One Docusaurus site, `BasisHub/Courses`, that hosts BASIS training "books" as plain reading material for BBj and DWC developers. It looks and behaves like https://docs.webforj.com, mirroring the tooling of `webforj/webforj-documentation`, and is served by GitHub Pages at `https://basishub.github.io/Courses/`. It starts with two books: "BBj DWC Training", moved in from the existing `BasisHub/DWC-Course` site, and "Introduction to BBj Development", converted once from a Moodle backup. More books will follow.

The full specification is `migration-seed.md` at the repo root. Treat it as the authoritative brief. This file records the scope and the decisions taken on top of it.

## Core Value

Both books read well and correctly on one public site in the webforJ look, and every old DWC-Course link still lands on the right page. After the migration, the Markdown is the only source of truth.

## Context

- Inputs in `import/`: `backup-moodle2-course-2-bbj_development_basics-*.mbz` (243 KB, converted to `intro-bbj`) and `backup-moodle2-course-4-bbjdwc-*.mbz` (16.7 MB, gap audit only; kept out of git or in LFS, location noted in `import/README.md`).
- Existing `BasisHub/DWC-Course` (Docusaurus 3.9.2, React 19, TS config, ~14,800 words, 12 chapters, ~50 images, 10 sample folders, own blue palette) is a condensed rewrite of Moodle course 4. Chapters 3 (DWC Debugging) and 12 (Deployment) have no Moodle counterpart.
- Reference repo `webforj/webforj-documentation` (MIT) supplies the SCSS, theme overrides, scripts, Vale styles and the CLAUDE.md shape. Its site lives in a `docs/` subfolder; this repo keeps the same convention.
- Moodle HTML is messy: `<br>` runs, inline span styles, `<pre>` without language classes mixing BBj/CSS/HTML, image filenames with spaces and timestamps, YouTube links stored as plain anchors.
- URL changes: DWC moves from `/DWC-Course/<path>` to `/Courses/docs/dwc/<path>`. GitHub Pages cannot redirect across repos, so the old repo becomes a meta-refresh redirect site.
- This local folder becomes `BasisHub/Courses`; the GitHub remote is added once the repo is created.

## Constraints

- **Tech stack**: Docusaurus 3.9 classic preset, SCSS via `docusaurus-plugin-sass`, Mermaid, `docusaurus-plugin-llms`, `plugin-client-redirects`, `docusaurus-plugin-zooming`; Python (lxml/BeautifulSoup + markdownify or pandoc) for the converter. Mirrors webforJ to keep the two repos navigable alike.
- **Hosting**: GitHub Pages via Actions, `url: https://basishub.github.io`, `baseUrl: /Courses/`, `routeBasePath: 'docs'`, `trailingSlash: false`.
- **Quality gates**: build must throw on broken links, anchors, Markdown links and images; Vale (Google + BASIS styles) must be clean; BBj code verified with the BBj documentation MCP (`bbj_lookup`, `bbj_check_syntax`), never guessed.
- **Naming**: kebab-case ASCII, two-digit position prefixes, exercises at `90-`+, content headings start at H2, every code fence has a language.
- **Licensing**: copied webforJ files keep their MIT notice.
- **Old links**: every public DWC-Course URL must keep resolving.
- **Assets**: Stephan supplies the BASIS-level logo and social cover; the phase that needs them asks for them.
