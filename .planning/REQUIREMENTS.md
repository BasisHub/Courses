# Requirements: BASIS Courses

**Defined:** 2026-10-03
**Core Value:** Both books read well and correctly on one public site in the webforJ look, every old DWC-Course link still lands on the right page, and the Markdown is the only source of truth after the migration.

Spec: `.planning/migration-seed.md`, corrected by `.planning/research/SUMMARY.md` where they disagree.

## v1 Requirements

### Site Foundation

- [x] **SITE-01**: Reader can open `https://basishub.github.io/Courses/` and see a book-card landing page listing every book (driven by a `src/data/books.js` registry)
- [x] **SITE-02**: Reader sees the webforJ/DWC look (copied `custom.scss` partial set, DWC tokens, theme overrides) in both light and dark mode, with the animated theme switcher and external-link decoration working under `/Courses/`
- [x] **SITE-03**: Reader gets each book at `/Courses/docs/<book>/...` with its own autogenerated sidebar and a navbar item per book (book icons on navbar and cards)
- [x] **SITE-04**: Every page loads fonts (Inter, JetBrains Mono) and `dwc-ui.css` from the site itself: no Google Fonts or CDN requests
- [x] **SITE-05**: Navbar shows the BASIS logo and the GitHub link, and the site uses the BASIS social cover and favicon (assets supplied by Stephan) plus the single-line BASIS copyright footer
- [x] **SITE-06**: Build fails on any broken link, anchor, Markdown link or Markdown image (all hooks at `throw`, each proven with a deliberate failure)
- [x] **SITE-07**: Site emits `sitemap.xml` and `llms.txt` / `llms-full.txt` covering both books under the `/Courses/` base URL
- [x] **SITE-08**: Reader can print a page cleanly (print stylesheet hides navbar, sidebar and TOC)

### Repository & CI

- [x] **REPO-01**: Every push to `main` builds and deploys the site to GitHub Pages (Node 24, `npm ci` in `docs/`, current Pages actions)
- [x] **REPO-02**: Every PR runs the site build without deploying, and runs Vale (Google + BASIS styles, `*.{md,mdx,txt}`, BBj vocabulary and acronym exceptions) failing on errors
- [x] **REPO-03**: Repo has `CLAUDE.md` (seed section 7, updated with research corrections), `CONTRIBUTING.md`, `.editorconfig`, and `THIRD_PARTY_NOTICES.md` plus MIT headers on files copied from webforJ
- [x] **REPO-04**: The whole `import/` folder (Moodle backups, unpacked trees) is gitignored and never committed or pushed; it is a temporary local workspace that is deleted once the migration is done. Nothing the site or later work depends on lives there
- [x] **REPO-05**: Dependencies pinned (Docusaurus 3.10.2 exact, lockfile committed); `tools/requirements.txt` pins the converter's Python packages

### Content Components

- [x] **COMP-01**: Author can write `:::exercise Try it yourself` and the reader sees a styled exercise box (DWC success palette) in both themes
- [x] **COMP-02**: Author can embed `<YouTube id="..." title="..." />` without an import, and the reader gets a responsive, lazy, privacy-enhanced (youtube-nocookie) player
- [x] **COMP-03**: BBj code fences are highlighted with `$`/`!` variables, labels, `#` fields, `rem` comments and keywords verified against the BBj documentation MCP (extending Prism's built-in grammar)
- [x] **COMP-04**: Code blocks longer than 40 lines are collapsible (`ExpandableCode`); every code block has a copy button
- [x] **COMP-05**: Author can use `Tabs`, `DocCardList`, Mermaid diagrams and wrapped tables (`TableWrapper`); images zoom on click
- [x] **COMP-06**: Reader can search all books with Cmd+K (local search); the Algolia config sits commented in place

### DWC Book Relocation

- [ ] **DWC-01**: All DWC-Course chapters appear under `/Courses/docs/dwc/` with unchanged text (pure relocation commit), flat numbered chapters, overview first
- [x] **DWC-02**: DWC images live colocated in each chapter's `img/` with kebab-case names, rendered as plain Markdown images; the rename map is committed as data in `tools/data/`
- [x] **DWC-03**: DWC samples are downloadable from `static/files/dwc/` and present as plain source in `examples/dwc/`, kept in sync by script (LICENSE and README kept)
- [x] **DWC-04**: Old DWC-Course `build/` and `sitemap.xml` are snapshotted before the move as input for redirects

### Intro-BBj Conversion

- [x] **CONV-01**: `tools/moodle2docusaurus.py` converts the course-2 backup and prints a report whose unresolved counts (files, `$@…@$` tokens, links, unclassified code) are all zero; every generated file compiles as MDX
- [x] **CONV-02**: Reader can read the "Introduction to BBj Development" book with chapter order matching the Moodle outline (28 chapter pages plus overview)
- [x] **CONV-03**: Converted code appears in language-tagged fences with no leftover HTML entities or `<br>` artefacts
- [x] **CONV-04**: All 10 intro videos appear as `<YouTube>` embeds
- [x] **CONV-05**: All 8 referenced intro images appear with hand-written alt text
- [x] **CONV-06**: Reader can download the intro sample files (`BetterHelloWorld.bbj`, the OO samples ZIP, `Sample.bbj`, `samples.zip`), each resource unpacked into its own folder in `examples/intro-bbj/`
- [x] **CONV-07**: Converter and generated docs are committed separately; afterwards the Markdown is the source of truth

### Exercises

- [x] **EXER-01**: Reader finds every intro-bbj exercise (5 Moodle assignments) as its own `9N-exercise-*.mdx` page after its section's chapters
- [x] **EXER-02**: Reader finds DWC exercises as exercise pages: inline exercises extracted, missing ones taken from the course-4 assignments
- [x] **EXER-03**: Reader can open a per-book exercise index listing all exercises of that book
- [x] **EXER-04**: Where a sample solution exists, the exercise page offers it in a collapsed "Possible solution" block

### DWC Gap Audit (before go-live)

- [x] **AUDIT-01**: `tools/data/dwc-gap-audit.md` lists, per Moodle course-4 page/book chapter, the paragraphs, code samples and screenshots missing from the DWC book with a keep / drop / already-covered verdict
- [x] **AUDIT-02**: Kept material is added to the DWC pages as its own commit series, without renaming existing slugs
- [x] **AUDIT-03**: DWC screenshots that originate from 2022-era Moodle images (matched by content hash) carry a `{/* TODO: screenshot outdated? */}` marker

### Review & Quality

- [ ] **QUAL-01**: Both books are hand-reviewed (headings, fences, entities, alt text, overviews, light and dark mode) and fixes are made in the Markdown
- [ ] **QUAL-02**: Vale reports zero issues across all content
- [ ] **QUAL-03**: Every `.bbj` under `docs/examples/` passes `bbj_check_syntax` (local pre-commit gate via the BBj MCP)
- [ ] **QUAL-04**: `docs/ROADMAP.md` carries the useful open items from DWC-Course's `.planning/` (Algolia, etc.)
- [ ] **QUAL-05**: The intro book's last page and the DWC book's overview link to each other as next steps

### Go-Live

- [ ] **LIVE-01**: Acceptance passes: build green, grep for `PLUGINFILE|pluginfile\.php|\$@[A-Z]+|moodle\.basis-europe|DWC-Course/` in `docs/docs` empty, sidebar orders diffed against Moodle outline and old site, PR build green
- [ ] **LIVE-02**: Site is live on GitHub Pages, and a deep URL loads all CSS, JS, fonts, images and search under `/Courses/`

### Redirects

- [ ] **REDIR-01**: Every old `https://basishub.github.io/DWC-Course/<path>` URL lands on the matching `/Courses/docs/dwc/<path>` page, preserving `#fragments` (meta refresh + canonical + fallback link + hash-forwarding script); unknown old paths hit a `404.html` that points to Courses
- [ ] **REDIR-02**: A script verifies every redirect target against the live Courses sitemap before the old repo is touched further
- [ ] **REDIR-03**: DWC-Course's README points to Courses and the repository is archived (only after redirects are verified live)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Login, enrolment, progress tracking, graded quizzes, submissions, due dates | Reading material only; no LMS features |
| Sync back to Moodle / re-running the converter on edited output | Markdown is the source of truth after conversion |
| Wholesale conversion of Moodle course 4 | DWC book comes from DWC-Course; course 4 only feeds the gap audit |
| Moodle course 3 | Superseded by course 4 |
| webforJ-specific components (ComponentDemo, DocChip, JavadocLink, MUI, gallery) | Not relevant to BBj content |
| i18n / translation pipeline | English only |
| Blog, versioned docs | Not needed for training books |
| Analytics, cookie banner | No IDs provided; self-hosting avoids consent needs |
| Live BBj playground | No server-side part |
| Re-hosting videos | Embed only |
| Custom domain | Staying on `basishub.github.io/Courses` |
| WAR/Maven/S3 hosting | GitHub Pages only |
