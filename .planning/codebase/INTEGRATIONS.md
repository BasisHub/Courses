# External Integrations

**Analysis Date:** 2026-10-04

## APIs & External Services

**Video Hosting:**
- YouTube (youtube-nocookie) - Videos embedded in course content
  - Component: `docs/src/components/YouTube/index.js`
  - Embeds via `https://www.youtube-nocookie.com/embed/{id}`
  - Watch links go to `https://www.youtube.com/watch?v={id}`
  - Used in MDX via `<YouTube id="..." title="..." />` component

**Search (Optional):**
- Algolia DocSearch - Commented out in config, optional future integration
  - Location: `docs/docusaurus.config.js` (lines 113-119, commented)
  - Would require `appId`, `apiKey`, `indexName` configuration

**BBj Documentation:**
- BBj Documentation MCP - Development-time lookup for API verification
  - Used via Claude Code tools: `bbj://primer`, `bbj_lookup`, `bbj_check_syntax`, `bbj_examples`
  - Not a runtime integration (development tool only)
  - Referenced in CLAUDE.md tool-calling conventions

## Data Storage

**Static Content:**
- Local filesystem only - No databases
- Source: Markdown/MDX files in `docs/docs/<book>/`
- Build output: Static HTML/CSS/JS in `docs/build/`

**File Storage:**
- GitHub Pages - Static hosting
- Samples/downloadable files: `docs/static/files/<book>/`
- Examples source: `docs/examples/<book>/`

**Caching:**
- Client-side only - No server-side cache
- Browser cache headers managed by GitHub Pages defaults

## Search & Indexing

**Search Implementation:**
- `@easyops-cn/docusaurus-search-local` - Offline, client-side search
  - Builds index during site build, embedded in output
  - No server-side search API
  - Configured in `docs/docusaurus.config.js` under `themes`
  - Index location: Embedded in built site (generated by `docusaurus-plugin-llms`)

**LLM-friendly Indexing:**
- `docusaurus-plugin-llms` 0.6.1 - Generates `llms.txt` and `llms-full.txt`
  - Configuration: `docs/docusaurus.config.js` lines 72-87
  - Excludes `docs/docs/authoring/**` (component fixture, not a book)
  - Output files: `docs/build/llms.txt`, `docs/build/llms-full.txt`

## CI/CD & Deployment

**Hosting:**
- GitHub Pages (free tier)
- Repository: `https://github.com/BasisHub/Courses`
- Base URL: `https://basishub.github.io/Courses/`

**CI Pipeline:**
1. **On push to main:** `.github/workflows/deploy.yml`
   - Builds site with `npm run build`
   - Checks sample sync with `tools/sync-samples.py --check`
   - Uploads artifact to GitHub Pages
   - Deploys to production

2. **On pull request:** `.github/workflows/test-build.yml`
   - Builds site to verify no broken links
   - Checks sample sync
   - Does not deploy

3. **On pull request:** `.github/workflows/reviewdog.yml`
   - Runs Vale prose linting
   - Posts findings as PR review comments
   - Fails CI if error-level violations found

**Build Validation:**
- `npm run build` - Docusaurus build with strict link/anchor checking
  - `onBrokenLinks: 'throw'` - Fails on missing internal links
  - `onBrokenAnchors: 'throw'` - Fails on missing anchors
  - Markdown image/link validation via hooks
- `tools/sync-samples.py --check` - Verifies sample files match their destinations
