lib/behaviour.js
  export function behaviourTest(id, title, opts, body)
    id: manifest id (e.g. 'dwc/01_GUI2BUI2DWC/DWC2.bbj') or fixture id ('fixture/known-good.bbj')
    opts: { issue?: 3|4|5|6|7, startDialog?: { button } | null, expectFailure?: boolean }
    body: async ({ page, app, note }) => void   // use Playwright expect; throw = fail; note(text) adds evidence
    Test title: `[${id}] issue #${issue}: ${title}` when issue is set, else `[${id}] ${title}`.
  export class BlockedError extends Error  // throw new BlockedError(reason) from a body when the check cannot be made (for example the oracle element is missing); outcome blocked, evidence = reason
    Outcome: blocked when the start state is not the kind's expected state (window/starter -> 'window', print -> 'console', dialog -> 'dialog'); evidence = 'sample did not start (<state>): <classify reasons>'. Else pass when the body returns, blocked when it throws a BlockedError (evidence = its message), fail when it throws anything else (evidence 'failed: <first line of the error>'); a BBj !ERROR in the console after the body turns the outcome into fail with '!ERROR=<code> <message> at line <line>'. Evidence is redacted. A screenshot `<app>--<slug(title) cut to 40>` is taken after the body. The result goes to results/behaviour (results/selftest-behaviour for fixture ids). The test then asserts outcome === 'pass' (red tests are findings).
results/<dir> layout: samples/, selftest/, behaviour/, selftest-behaviour/, screenshots/, console/, debuglog/, compile.json, run.json, baseline.json
