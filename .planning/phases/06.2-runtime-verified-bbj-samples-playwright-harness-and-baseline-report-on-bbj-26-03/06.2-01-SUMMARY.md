# Phase 06.2 Plan 01: BBj administration layer

**A license-free Java Admin API tool, Node wrappers, a run lock and a cleanup command, verified live against BBjServices 26.03.**

## Accomplishments

- `admin/BBjAdminTool.java`, evolved from the spike's AdminProbe: status (licenses, sessions), register-many, apps, unregister (courses- prefix only), killids, scan (secret scan of a file).
- `lib/paths.js`: main checkout and worktree roots, `.env` lookup (path only), settings allowlist (BBJ_HOME, BBJ_URL, JAVA_BIN), `resultsDir` (fixed later in `c76a524` to return file paths for names with an extension).
- `lib/lock.js`: run lock in the OS temp folder, `wx` create, heartbeat every 5 minutes, atomic takeover by rename, 4 hour stale age, `COURSES_LOCK_WAIT_MS`.
- `lib/admin.js`: spawn wrapper (argument arrays, 90 s default, 300 s for register-many and unregister), output parsers, anchored `isHarnessSession`, run snapshot.
- `cleanup.mjs` and the npm scripts `test:unit`, `selftest`, `samples`, `compile`, `report`, `cleanup`, `baseline`.

## Live verification (2026-10-09, orchestrator)

- Task 2: `ADMIN-LIVE-OK` (status: BBJ total 3, WEBCUI total 2; secret scan CLEAN on package.json; prefix guard exit 3 for `demo-`); `node --test lib/admin.test.js` 9 of 9.
- Task 3: `register-many` for two probe apps in 5.9 s; `courses-probe-admin` got `http://BasisLap:8888/webapp/courses-probe-admin`; `courses-probe-missing` was refused with `no such program: .../does-not-exist.bbj`; `REGISTER-OK`; `node cleanup.mjs` printed `terminated 0 harness session(s)`, `removed 1 app(s)`, `CLEAN`; `NO-COURSES-APPS`.
- Program name format of sessions (from the spike, same API): forward-slash absolute paths, for example `C:/Users/.../docs/examples/.../X.bbj`, or `<initializing>` before the program is loaded.

## Deviations from Plan

1. **Worktree base:** the executor's worktree started at 2df66a9; it fast-forwarded to `sample-tests` (763d48a) before work. Nothing was rewritten.
2. **Prefix guard moved earlier (Rule 2):** `unregister` refuses a bad prefix before reading credentials or connecting.
3. **Extra test file (Rule 2):** `lib/admin-tool.test.js` covers the guards that need no server.
4. **Lockfile criterion:** compared against 763d48a instead of main, which has no lockfile.
5. **`RegExp.exec` replaced** by `String.match` so the `grep "exec("` acceptance check stays empty.
6. **Additions:** `..` segments normalized in `isHarnessSession`; the Java tool forces UTF-8 output.
7. **Speed:** each Java source launch takes several seconds because the whole `.lib` folder is on the classpath; callers should batch.

## Issues Encountered

- A rate limit interrupted the executor after Task 1's tests; it resumed from its transcript.
- BBjServices was down when Tasks 2 and 3 first ran (checkpoint), then came up through the Services Wizard without Jetty: `status` worked while `apps` and `register-many` failed inside BBjServices with `NullPointerException`. Nothing was registered. After Eric restarted BBjServices normally, both live checks passed.
