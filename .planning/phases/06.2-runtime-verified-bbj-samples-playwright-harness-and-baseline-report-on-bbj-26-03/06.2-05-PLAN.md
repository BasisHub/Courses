Give every Playwright run a safe session lifecycle on Eric's BBjServices: lock, sweep, register, run serially in Chromium, terminate each test's sessions, sweep, unregister, unlock.

This plan proves the lifecycle with the known-good fixture before plan 08 adds observation and classification.
Output: lib/apps.js, playwright.config.js, global-setup.js, global-teardown.js, lib/fixtures.js, tests/selftest.spec.js (lifecycle tests).
