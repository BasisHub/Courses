# Phase 1 — UI Design Contract

> Visual and interaction contract for the Docusaurus scaffold. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Principle: the design system is NOT invented here. It is the webforJ docs look (docs.webforj.com): copied SCSS partials from `webforj/webforj-documentation/docs/src/css/` on top of the vendored DWC `dwc-ui.css` tokens (D-10) and Infima defaults. Executors copy and trim, they do not restyle. Only four pieces of new CSS exist: the landing intro block, the book-card grid details, navbar book icons, and the print stylesheet.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn is not applicable: Docusaurus/Infima site, not a React app shell; no `components.json`) |

## Spacing Scale

All values are DWC `--dwc-space-*` / Infima spacing utilities. Do not hard-code pixels in new SCSS; use the tokens or Infima utility classes (`padding--lg`, `margin-bottom--lg`).

Declared scale (multiples of 4, as rendered at 16px root):

| Token | Value | DWC token / Infima | Usage |
|-------|-------|--------------------|-------|
| xs | 4px | `--dwc-space-xs` | Icon-to-label gap in navbar items |
| sm | 8px | `--dwc-space-s` | Gap between card icon and title |
| md | 16px | `--dwc-space-m`, `--ifm-spacing-horizontal` | Default element spacing, card grid gutter |
| lg | 24px | `--dwc-space-xl`, `padding--lg` | Card inner padding, intro block bottom margin |
| xl | 32px | `--dwc-space-3xl` | Landing top padding |
| 2xl | 48px | Infima `margin-vert--xl` equivalent | Space between intro block and footer on landing |
| 3xl | 64px | n/a | Not used in this phase |

Exceptions:
- Book icon mask: 28px (1.75rem) square on cards, 20px (1.25rem) in the navbar; icon sizes are not spacing.
- Navbar height, sidebar width, TOC width and content max-width are inherited unchanged from webforJ partials (`_navbar`, `_sidebar`, `_toc`, `_content`).
- Touch targets: Infima navbar and card links already exceed 44px; do not shrink them.

## Typography

Inherited from webforJ/Infima; this phase declares only the four sizes the new landing page and chrome use.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (intro line, doc text) | 16px (`--ifm-font-size-base`: 100%) | 400 | 1.65 (`--ifm-line-height-base`, Infima default; kept for webforJ parity) |
| Label (card blurb, navbar, TOC, sidebar) | 14px (0.875rem, as `_category.scss` card `p`) | 400 | 1.65 |
| Heading (card title, H2 in content) | 24px (`--ifm-h2-font-size`: 1.5rem) | 700 | 1.25 (`--ifm-heading-line-height`) |
| Display (landing H1 "BASIS Training Books") | 32px (`--ifm-h1-font-size`: 2rem) | 700 | 1.25 |

Weights: exactly 2 in new rules, regular 400 and bold 700 (Infima heading default; webforJ does not override). Do not introduce 500/600 in new CSS. Code uses JetBrains Mono at Infima `--ifm-code-font-size` (90%).

## Color

All colors come from DWC tokens mapped in `custom.scss`. Do not add hex values. Light and dark are both mandatory and are resolved by the tokens.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `--dwc-surface-3` (= `--ifm-background-color`) | Page background, doc content area |
| Secondary (30%) | `--dwc-surface-1` / `--dwc-surface-2`, `--navbar-dark-background-color` (permanent dark navbar), `--code-display-color-background` | Cards, sidebar, footer, code blocks, navbar |
| Accent (10%) | `--ifm-color-primary` (= `--dwc-color-primary-text`) | See reserved list below |
| Destructive | not used in this phase | No destructive actions |

Accent reserved for:
1. Book-card icon color (`.book-card__icon`, `color: var(--ifm-color-primary)`)
2. Book-card hover border (`--ifm-color-primary-lightest`, from `_category.scss`)
3. Active sidebar item and its background (`--dwc-color-primary-alt`)
4. Links inside Markdown content and TOC active item
5. Keyboard focus ring (`--dwc-color-primary-50`)

Navbar book items inherit the white-on-dark navbar color; hover uses `--navbar-dark-link-hover-color`, active uses `--navbar-dark-background-active`. Navbar icons use `currentColor`, so no accent there.

Known and accepted: the build prints a postcss-calc warning for `oklch(from … calc(c * 3) …)` in `--navbar-dark-background-color`. Not a failure.

## Layout and Interaction Contract

### Landing page (`src/pages/index.js`, D-01..D-04)
- Structure top to bottom: navbar, intro block, card grid, footer. No hero image, no banner, no CTA button.
- Intro block: one `H1` (Display) and one body-size paragraph, left-aligned inside the standard `container`, with `margin-bottom--lg` below the paragraph.
- Card grid: `<section className="row topics-section">` containing one `<article className="col col--6 margin-bottom--lg">` per book. 2 columns at >=997px, 1 column below (Infima breakpoint). Reuse `_category.scss` card look: no shadow, transparent background, thin primary-lightest border on hover. Do not use `row list` (single-column docs-index look). Do not use `DocCardList`.
- Card = `<Link className="card padding--lg book-card" to={book.to}>` with, in order: icon span (`aria-hidden="true"`), `Heading as="h2"` title, blurb `<p>`. Entire card is the click target. Height 100% so cards in a row align.
- Card contents: title, blurb, Tabler icon only (D-02). No tags, chapter count or prerequisites.
- Order: `books.js` order (intro-bbj, then dwc) on the page and in the navbar (D-04).
- States: default, hover (border), focus-visible (DWC focus ring, never removed), active (browser default). No loading state (static page). Empty state: not applicable (registry is never empty; if `books.js` is empty the page renders the intro only, which is a build-time developer error, not a user state).

### Navbar (D-07, D-09, D-14)
- Left: text-only title "BASIS Courses" (no logo image, no DWC-Course logo). Then two `docSidebar` items: "BBj Basics" (intro-bbj), "DWC" (dwc), each with its Tabler mask icon (`.navbar__item.navbar-book::before`).
- Right: dark/light toggle only. No GitHub link, no search, no dropdown, no locale dropdown.
- Active state: the item for the current book is highlighted via Docusaurus active class using the copied `_navbar.scss`.
- Mobile: standard Infima hamburger drawer containing the same two items.

### Docs pages
- One autogenerated sidebar per book; chapter folders show numbering stripped, no chapter icons (only books carry icons). Category links use the stripped doc id.
- Breadcrumbs, prev/next pagination, TOC (H2 and H3) as in webforJ partials (`_pagination`, `_toc`, `_content`). Edit link points to `https://github.com/BasisHub/Courses/tree/main/docs/` (D-15).
- Content headings start at H2; every code fence has a language.

### Footer and announcement (D-13, D-14)
- Footer: single line, copied `_footer.scss`; no brand assets and no link columns until Phase 3.
- Announcement bar: off. Keep `_announcement.scss` and a commented `announcementBar` config block.

### Theme
- Follows system; toggle uses `docs/static/js/dwc-theme-switcher.js` with its script path built from the baseUrl constant. Both modes must be screenshot-checked (landing and one doc page).
- All asset URLs (scripts, fonts, `dwc-ui.css`) are baseUrl-prefixed (`/Courses/`).

### Print stylesheet (`_print.scss`, SITE-08)
- Hide: navbar, sidebar, TOC, breadcrumbs, footer, edit link, pagination, theme toggle, announcement bar.
- Show: content at full width, black text on white regardless of color mode, code blocks wrapped (`white-space: pre-wrap`), `break-inside: avoid` on code blocks, tables and images.
- Optional: append external link URLs after links. Skip if it stacks badly with the external-link `↗` decorator.
- Verified by headless-Chrome print-to-PDF and `pdftotext` (see RESEARCH validation row SC5).

### Accessibility
- Cards are real links (`<a>`), one heading per card (H2 under the page H1). Icons are decorative and `aria-hidden`.
- Text contrast comes from DWC tokens in both modes; do not override colors on new elements.
- Focus rings stay visible; respect `prefers-reduced-motion` for the theme-switch view transition if the copied script does not already.
