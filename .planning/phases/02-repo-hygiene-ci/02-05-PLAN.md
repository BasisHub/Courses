<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local machine to public GitHub | Entire git history becomes world-readable |
| Actions to Pages | Deploy job publishes whatever docs/build contains |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-17 | Information disclosure | Full git history push | mitigate | Task 1 scans all revisions for credentials, checks no `import/`/`.claude/` path ever committed, and lists large blobs; blocking checkpoint before push |
| T-02-18 | Information disclosure | .planning/ in public history | accept | D-03 and D-04 accept public planning docs and the internal Moodle host name |
| T-02-19 | Elevation of privilege | Default GITHUB_TOKEN permissions | mitigate | Repo default workflow permissions set to `read`; workflows declare their own minimal `permissions` |
| T-02-20 | Information disclosure | Future accidental secret commits | mitigate | Enable secret scanning and push protection via API; record result |
| T-02-21 | Tampering | Pages deployment | mitigate | Deploy only from `deploy.yml` on push to main through the `github-pages` environment; Pages source `workflow`, no `gh-pages` branch |
| T-02-22 | Spoofing | Wrong account or org | mitigate | Task 1 confirms gh account and BasisHub admin role; checkpoint shows exact commands |
</threat_model>
