## Accomplishments
- Solution 83 injects `light.css` and `shoelace.js` (type=module) from the two pinned 2.20.1 `cdn/` URLs, adds `sl-rating` with `addWebComponent`, ships `String(event.target.value)` through `newEventOptions` and `addItem`, and shows the value in a `BBjStaticText` from the `onRatingChange` label.
- Solution 122 starts from the CSS grid exercise solution, replaces the inline `JsonObject` panel style with `addPanelStyle("contact-form")`, tags the Company label and edit box with `optional-field`, and reads `Exercise-MediaQueriesComplete.css`, which holds the grid and `@media (width < 600px)` (one column, smaller font, Company hidden). The Submit button spans all columns in both layouts through `grid-column: 1 / -1`.
- Solution 123 puts the class `grow-button` on a `BBjButton`; the CSS transitions `transform`, scales to 1.2 on hover and sets `transition: none` under `prefers-reduced-motion: reduce`.
- All CSS uses only `--dwc-*` tokens declared in `docs/static/css/dwc-ui.css` (space-s, space-m, space-l, space-xl, font-size, font-size-s); no color literal and no legacy `--bbj-` property.
