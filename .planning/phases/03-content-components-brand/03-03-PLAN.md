| Boundary | Description |
|----------|-------------|
| reader browser -> YouTube/Google | Third-party request, allowed only after an explicit click |
| author MDX props -> iframe URL | id/title from page source build the embed URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | Information disclosure | YouTube facade | mitigate | No iframe, thumbnail or script before click (D-08/D-09); nocookie host; consent line (D-10); 03-06 greps built HTML for iframe/ytimg/youtube.com/embed |
| T-03-08 | Tampering | iframe src from id prop | mitigate | id must match ^[A-Za-z0-9_-]{11}$, fixed https host, encodeURIComponent; never accept a URL prop |
| T-03-09 | Spoofing | iframe sandboxing | accept | Embedded player is YouTube's own origin; allow list limited to autoplay, encrypted-media, picture-in-picture, fullscreen |
| T-03-10 | Elevation | forbidden webforJ components | mitigate | Grep gate for DocChip/JavadocLink/ComponentDemo/@mui |
